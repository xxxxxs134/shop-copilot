## 结果分析（为什么 RAG 组反而低 3 分）

失败的 3 题（Q3 标题字符数 / Q5 FABE 结构 / Q11 退款率后果）均为**种子语料未覆盖的具体细节**：

- RAG 组：诚实回答"知识库未覆盖"，并引用了语料中的相关原则 → 行为正确（防编造），但裁判按"无确切答案"给 1 分
- 无 RAG 组：DeepSeek 靠预训练常识答出了具体数字 → 裁判按"具体且正确"给 2 分

**结论**：
1. 对**公开常识**（平台通用规则），裸模型已足够强，RAG 的增量价值有限
2. RAG 的真正价值在于：(a) **私有/新鲜数据**（语料外知识模型答不出）；(b) **防编造**（宁可说"未覆盖"也不 hallucinate）；(c) **可溯源引用**（[1][2] 角标可核对原文）
3. 竞赛演示建议：用**语料外数据**（如"我们的内部 SOP 规定响应时间是 X 分钟"）对比开关 RAG，才能拉开差距
4. 语料扩充方向：优先补真实平台规则原文（数值型细节），而非方法论文章

> 淘宝 DSR 评分通常包含以下三项：宝贝与描述相符、卖家服务态度、物流服务，每项由买家以 1—5 星打分 [1]。

**Q2: 新手开店保证金大概需要多少？**

> 知识库未覆盖具体金额。保证金标准因平台、经营类目和店铺类型（个人店/企业店）而异，多数平台对不同类目设置不同保证金标准，具体金额需以各平台商家后台的最新说明为准。[1]
