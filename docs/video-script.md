# 店智 Copilot — 演示视频脚本（5-8 分钟）

> 用途：录屏 + 旁白，按分镜顺序录制。标注 ⏱ 为时间预算。

## 开场（30s）

- 画面：首页 + 一句话标题动画
- 旁白：
  > 「中小电商卖家每天面对海量规则查询、数据解读和文案工作。店智 Copilot 是一个电商运营 AI Agent 助手——不只是聊天，它会查数据、查知识库、生成文案、检查合规，并把每一步思考过程展示给你。」

## 1. RAG 知识库问答（90s）

- 画面：切到「RAG 问答」模式 → 输入「淘宝 DSR 评分包含哪三项？」
- 重点展示：回答末尾的 `[1]` 引用角标，鼠标悬停/点击可见原文出处
- 旁白：
  > 「内置 40 篇电商运营知识库，采用 BM25 + 向量混合检索（RRF 融合）。回答基于检索到的原文，标注引用编号，可溯源、不编造。评测显示：知识库未覆盖的问题，它会明确说'未覆盖'而不是瞎编——这是企业级 RAG 该有的样子。」
- 可插入：`docs/rag-eval-v2.md` 的结果表格一闪而过

## 2. Agent 多步推理（120s）★ 核心亮点

- 画面：切到「Agent 模式」→ 输入「查店铺今日数据并给建议」
- 重点展示：
  1. 步骤卡片实时出现：📊 数据查询（第 1 步：GMV/订单/访客）
  2. 第二张卡片：📊 数据查询（第 2 步：热销品/流量来源）
  3. 流式输出完整分析报告（表格 + 6 条建议 + 优先动作）
- 旁白：
  > 「Agent 模式运行手写 ReAct 循环：模型自主决定调用什么工具、调用几次。这里它两次调用数据查询工具，拿到完整店铺数据后，给出转化率诊断、流量结构分析和可执行的优先级建议。整个过程像人类运营一样'先查数、再分析、后建议'，且每一步都可视化。」
- 可提技术点（字幕形式）：「DeepSeek function calling · 手写循环 · 无 LangChain」

## 3. 多模态（90s）

### 3a. 图生文案（45s）
- 画面：点 🖼️ 上传一张商品图（提前准备一张 T 恤/充电宝白底图）
- 重点展示：识别结果卡片（标题/卖点/描述）→ 自动填入输入框 → 可编辑后发送
- 旁白：
  > 「上传商品图，GLM-4V 视觉模型自动生成标题、卖点和描述，直接进入输入框，改一改就能用。」

### 3b. 语音输入（30s）
- 画面：点 🎤 说话「帮我看看退款率太高怎么办」→ 文字上屏 → 发送
- 旁白：
  > 「支持语音输入，动动嘴就能提问。」

## 4. MCP 开放生态（60s）

- 画面：终端运行 `npx @modelcontextprotocol/inspector python -m backend.mcp_server` → Inspector 界面调用 kb_search → 返回结果
- 旁白：
  > 「所有能力通过 MCP 协议标准化暴露。这意味着店智 Copilot 的工具可以被任何支持 MCP 的 AI 客户端复用——Claude Desktop、Cursor 等，一次开发，生态互通。」
- 字幕技术点：FastMCP · stdio · 4 tools

## 5. 架构总结（60s）

- 画面：README 里的架构图（可做轻微缩放动画）
- 旁白：
  > 「架构上遵循比赛规则：前端 Next.js 只负责交互，一切 AI 能力——DeepSeek、RAG、Agent、MCP、视觉模型——都收敛在 Python FastAPI 接入层。前后端职责清晰，密钥零暴露。」
- 字幕逐行浮现：前端（Next.js + TS）→ FastAPI 接入层 → Agent 内核 / RAG / MCP → DeepSeek · GLM-4V

## 收尾（30s）

- 画面：回到首页，Logo + GitHub 链接（如有）
- 旁白：
  > 「店智 Copilot——会查数、会引用、会思考的电商运营 AI 助手。欢迎试用与交流。」
